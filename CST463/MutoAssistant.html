Configuring the Robot's Assistant Client and Server

This page documents how to configure the robot and a separate laptop for running the Muto Assistant Client and Server programs.

The Server

The server is hosted on an external device and requires three python programs, which are assistantServer.py, speech.py, and geminiModule.py. Prior to running them, these libraries must be installed via this command or nay variation to get it working in your environment: "pip install PyAudio google-genai gTTS SpeechRecognition pygame python-dotenv"
Additionally, a .env file must be created that contains a variable named API_KEY that is set to your personal Gemini API key. Then, you must make sure the Gemini model specified in geminiModule.py matches the one you desire to use. Also, certain devices on operating systems such as MacOS or Linux may have issues with installing certain libraries such as PyAudio. Also, pygame.midi may experience issues on MacOS if the MIDI instrument output is not manually enabled.

The Client

The program for the client, which is the robot, is named mutoAssistantClient.py and it only needs pygame and MutoLib to be installed, which should already be in your environment if previous projects have been ran. The assistantServer.py must be ran on the laptop first, and then the IP address of the laptop must be entered into the console of the program to connect and begin operation. The client program should be ran with the command python3.12.
