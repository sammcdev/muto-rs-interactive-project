Current Input

    Controller Input
  • D-Pad Up: Move Forward
  • D-Pad Down: Move Backwards
  • D-Pad Left: Move Left
  • D-Pad Right: Move Right
  • Left Bumper: Rotate Left
  • Right Bumper: Rotate Right
  • Left Trigger: Decrease Speed
  • Right Trigger: Increase Speed
  • Select: Decrease Step Length
  • Start: Increase Step Length
  • X: Dance
  • Y: Peacock Spider Dance
  • A: Buzzer
  • B: Wave
